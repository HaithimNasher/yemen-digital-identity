# Registrar Accreditation Policy — Draft

Status: `DRAFT`

## Purpose

Define a transparent process for organizations that may integrate with a future `.ye` registry platform.

## Accreditation flow

1. Application
2. Legal/document review
3. Security review
4. Technical conformance testing
5. Sandbox certification
6. Agreement
7. Production activation
8. Continuous compliance

## Minimum controls

- strong authentication
- MFA for privileged accounts
- secure credential storage
- encrypted transport
- registry API conformance
- audit logging
- privacy controls
- abuse contact
- incident escalation
- business continuity

## Separation of responsibilities

The registrar manages the registrant relationship.

The registry:
- maintains authoritative registry state
- enforces namespace policy
- manages lifecycle rules
- publishes zone data
- provides RDAP
- records registrar actions in immutable or tamper-evident audit logs
