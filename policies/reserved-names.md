# Reserved Names Policy — Draft

Status: `DRAFT`

This document is a policy model for YDII Professional v2. It does not reserve names in any operational registry.

## Classes

### 1. State and public institutions
Examples may include:

- presidency-related labels
- cabinet-related labels
- parliament-related labels
- ministry or authority abbreviations

### 2. Registry infrastructure
Examples:

- `nic`
- `registry`
- `rdap`
- `whois`
- `dns`
- `epp`
- `www`

### 3. Security-sensitive services
Examples:

- `login`
- `id`
- `payment`
- `portal`
- `auth`
- `sso`

### 4. Technical protocol labels
Protocol-reserved or infrastructure-critical labels should be reviewed against applicable Internet standards before allocation.

## Controls

Reserved labels must have:
- policy owner
- reason
- scope
- status
- approval authority
- audit record
- release procedure, if release is ever permitted
