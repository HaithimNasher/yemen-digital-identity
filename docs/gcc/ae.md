# United Arab Emirates — `.ae`

## Model
`.aeDA`, a TDRA department, acts as regulatory body and registry operator and explicitly uses the Registry–Registrar model.

## Relevant design patterns for YDII
- direct `.ae` registration
- restricted sector zones
- local and international accredited registrars
- Arabic `.امارات`
- public policy/dispute architecture
