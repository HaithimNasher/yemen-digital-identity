# Saudi Arabia — `.sa`

## Model
SaudiNIC operates the Saudi namespace and publishes rules covering `.sa`, sector zones, licensed registrars and `.السعودية`.

## Relevant design patterns for YDII
- explicit per-zone eligibility
- licensed registrar ecosystem
- DNSSEC Practice Statement
- Arabic national IDN
- public registration regulations
