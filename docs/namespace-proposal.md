# Proposed Yemen Namespace Model

> هذه **مسودة بحثية** وليست بنية معتمدة رسميًا.

## المستوى الحالي المعروف
من الفئات المستخدمة والمتداولة تحت `.ye`:
- `.gov.ye`
- `.edu.ye`
- `.com.ye`
- `.net.ye`
- `.org.ye`

## خيارات تُدرس مستقبلًا
- التسجيل المباشر: `example.ye`
- أفراد: `name.ye`
- مدارس: `sch.ye`
- صحة: `med.ye`
- مهن: `pro.ye`
- تراث/متاحف: `museum.ye`

أي إضافة يجب أن تسبقها:
- دراسة الطلب.
- تحليل التداخل.
- سياسة أهلية.
- سياسة أسماء محجوزة.
- آلية نزاعات.
- مراجعة تقنية وأمنية.
