# YDII Policy Center

The Policy Center is a draft governance library for YDII Professional v2.

## Current coverage

- Registration
- Eligibility
- Registrar Accreditation
- Reserved Names
- Domain Lifecycle
- Privacy / RDAP
- WHOIS / RDAP transition
- Abuse
- Disputes
- Transfer
- Renewal / Expiry
- DNSSEC
- Arabic IDN research

## Important distinction

These documents are architecture and policy prototypes.

They are not:
- official `.ye` policy
- legal advice
- registrar contracts
- operational registry rules

The project intentionally leaves unresolved policy variables unset instead of inventing values.
