# GCC ccTLD Benchmark

هذه الوثيقة تقارن **عناصر قابلة للدراسة** من دول الخليج، وليست ترتيبًا أو تقييمًا سياسيًا أو مؤسسيًا.

| الدولة | ccTLD | أمثلة على التصنيفات/الممارسات |
|---|---|---|
| السعودية | `.sa` | تسجيل مباشر + فئات مثل `com.sa`, `net.sa`, `org.sa`, `edu.sa`, `gov.sa`, ودعم `.السعودية` وDNSSEC |
| الإمارات | `.ae` | تسجيل مباشر + فئات مقيدة، ودعم `.امارات` |
| قطر | `.qa` | تسجيل مباشر + فئات مؤسسية وأفراد/تعليم، ودعم `.قطر` |
| الكويت | `.kw` | فئات مثل `com.kw`, `net.kw`, `org.kw`, `edu.kw`, `gov.kw` |
| عُمان | `.om` | فئات قطاعية متعددة، ودعم `.عمان` |
| البحرين | `.bh` | Registry/Registrar ecosystem، ودعم `.البحرين` |

## ما الذي ندرسه لليمن؟
1. التسجيل المباشر تحت `.ye`.
2. الفئات القطاعية عند الحاجة.
3. نموذج Registry/Registrar.
4. DNSSEC.
5. RDAP وشفافية البيانات.
6. IDN العربي.
7. سياسات الأسماء المحجوزة والنزاعات.
