# Ministries dataset from user screenshots

تم بناء قائمة الوزارات في `data/entities/ministries.json` اعتمادًا على صور Domain Manager التي قدمها المستخدم.

## عدد الوزارات
26 وزارة.

## سياسة البيانات
- `name_ar`: الاسم كما ظهر في الصور.
- `current_domain`: اسم النطاق كما ظهر في الصور.
- `reference_ipv4`: عنوان IPv4 كما ظهر في الصور فقط.
- `verification_status`: `screenshot-reference`.

هذه البيانات ليست بديلاً عن DNS/RDAP أو مصدر رسمي.
