# YDII National Entity Directory

The national directory separates **entities** from **namespace policy**.

## Active datasets
- Ministries
- Public universities

## Planned datasets
- Authorities & public institutions
- Schools
- Companies
- Banks & financial institutions
- Telecom & Internet providers
- Healthcare
- Organizations & associations

## Data integrity rule
A domain shown as `PROPOSED` must not be interpreted as registered, owned, operational, or official.

Live DNS/RDAP validation belongs to the future Observatory layer, not to the static directory dataset.
