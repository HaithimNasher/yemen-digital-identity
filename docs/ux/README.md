# YDII Professional UX

Step 11 introduces a shared bilingual UI shell for the static portal.

## Features

- Arabic / English navigation
- RTL / LTR switching
- language preference persisted in local storage
- light / dark theme
- responsive navigation
- shared visual design system
- skip-to-content accessibility link
- focus-visible states
- reduced-motion support
- consistent project disclaimer
- shared footer / project identity

## Scope

This step provides a bilingual **navigation and platform shell**.

Some page-specific data/content remains in its original language where the underlying dataset itself is Arabic or English.

## Integrity

The shared interface always retains the project disclaimer:

> YDII is an open-source research and engineering project and is not the official `.ye` registry.
